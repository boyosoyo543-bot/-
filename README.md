# WhatsApp Sticker Moderator

بوت واتساب خاص بالكروبات.

البوت كيراقب الستيكارات داخل الكروب، ومنين شي عضو يرسل أكثر من 5 ستيكرات خلال 30 ثانية، كيحاول يطردو.

## المميزات

- الربط عبر WhatsApp Pairing Code.
- مراقبة الكروبات فقط.
- تجاهل الرسائل الخاصة.
- تجاهل الأدمنز.
- طرد العضو عند تجاوز الحد.
- حفظ جلسة واتساب داخل Volume.
- Health endpoint لـ Railway.

## التشغيل محلياً

خاصك Node.js 20 أو أحدث.

```bash
npm install
cp .env.example .env
npm start
